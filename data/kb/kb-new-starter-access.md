# New starter access and onboarding checklist

New starters need accounts and equipment ready on day one. This takes IT **5 working days**, so managers must raise the request early.

## For managers (at least 5 working days before the start date)

1. Raise a ticket with the category **New Starter** in the helpdesk portal.
2. Include the starter's full name, start date, job title, department, manager and location (office or remote).
3. List the systems they need and the shared drives they should join. If unsure, say which existing colleague has the same role and IT will copy their access.
4. Request any non-standard equipment separately (see the Equipment requests article).

Late requests are handled as best we can but cannot be guaranteed for day one.

## What IT sets up

- Acme email address and Microsoft 365 licence
- A laptop with the standard software, collected from the IT desk on the first morning
- MFA enrolment appointment, 15 minutes on day one
- Access to the groups requested by the manager

## For the new starter on day one

1. Collect your laptop from the IT desk (floor 1) with photo ID.
2. Sign in with the temporary password in your welcome email and set a new password.
3. Set up Microsoft Authenticator (see the MFA setup article).
4. Install any extra software through the Software Centre.
5. Check that you can reach email, Teams and the shared drives. If not, raise a ticket.

## Contractors

Contractors follow the same process but get accounts that expire on their contract end date. The manager must say what that date is.

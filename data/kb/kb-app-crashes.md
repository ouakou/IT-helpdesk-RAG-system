# Application crashes and freezes

## First steps

1. Wait 60 seconds. Many apps are working and not frozen.
2. Close the app. If it will not close, force-quit it: Ctrl+Shift+Esc then **End task** on Windows, or Cmd+Option+Esc on macOS.
3. Reopen it. Office apps will offer to recover unsaved work.
4. Restart the laptop if the problem repeats.

## Apps that crash on opening

- Check for updates in the Software Centre or Self Service. Install any available.
- Repair the app: Windows Settings, Apps, find the app, **Advanced options**, **Repair**.
- Try opening without add-ins. For Office, hold Ctrl while opening and choose **Yes** to Safe Mode.

## Browser freezes

Close extra tabs, then clear the cache (Settings, Privacy, Clear browsing data, last 7 days). Try a private window to rule out extensions.

## Teams freezes or crashes

Quit Teams fully from the system tray, then reopen. If that fails, clear the Teams cache. See the Microsoft 365 and Teams article.

## Collect details before you raise a ticket

Raise a ticket with the category **Software**. Include:

- the app name and version
- what you were doing when it crashed
- the exact error message (a screenshot helps)
- whether it happens every time or sometimes

## Data loss

If you lost unsaved work, check for an auto-recovered copy first. Files saved in OneDrive keep earlier versions. See the Backup and file recovery article.

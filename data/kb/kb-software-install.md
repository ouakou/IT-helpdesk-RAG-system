# Software installation and approved-software list

You cannot install programs directly on a company laptop. Software is installed from approved sources so it is licensed, patched and safe.

## Approved software

Open the **Software Centre** (Windows) or **Self Service** (macOS) and install any listed program yourself, with no ticket and no admin rights. The catalogue includes:

- Microsoft 365 apps, Teams and OneDrive
- Zoom (view-only for external meetings), Adobe Acrobat Reader
- 7-Zip, Notepad++, Visual Studio Code, Python 3.12
- Slack is not approved; use Teams.

## Software not in the catalogue

1. Raise a ticket with the category **Software Request**.
2. Give the name, version, link to the vendor, what you need it for, and how many people need it.
3. Your manager approves it, and the budget owner approves if it costs money.
4. IT carries out a **security and licence review**, which takes up to **10 working days**. You will be told if it is rejected and why.

## Not allowed

- Downloading installers from the internet and running them
- Pirated, cracked or "free trial" software without approval
- Browser extensions that read all web pages (extensions are limited to an approved list)

## Uninstalling

Use the same Software Centre or Self Service app. If you no longer need a paid licence, raise a ticket so it can be reassigned.

## Problems

If an install fails, try again after a restart. If it still fails, raise a ticket with the error message.

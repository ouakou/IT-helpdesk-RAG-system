# Software updates and patching

Security updates close known weaknesses that attackers use, so Acme installs them on every company laptop.

## How it works

- Windows and macOS updates are released on the **second Tuesday of each month**. After testing, they are pushed to laptops during the following week.
- Application updates (Office, browsers, Teams) install automatically in the background.
- Critical security fixes outside the monthly cycle can be pushed within 48 hours.

## What you will see

A notification asks you to restart. You can **postpone up to 3 times**, 4 hours each time. After the third postponement, the laptop restarts automatically at the next idle moment. Save your work when you see the first reminder.

## Good habits

- Restart or shut down at the end of each day, so updates can install overnight.
- Keep your laptop connected to power and Wi-Fi when updating. Do not switch it off during the "Working on updates" screen.
- On the VPN or on a slow home connection, large updates can take a while. Leave it connected until it finishes.

## If an update fails

If the laptop is stuck in an update loop or shows "Update failed", restart once. If it fails again, raise a ticket with the category **Software**, and include the update number if shown (for example KB5034123).

## If an update breaks something

Raise a ticket and say what stopped working and when. IT can roll back an update where needed. Do not uninstall updates yourself.

## Personal devices

Phones and tablets used for work email must be kept on the latest operating system version. See the Remote working and BYOD policy.
